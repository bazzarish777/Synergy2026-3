Алгоритм решения
Для выполнения поставленной задачи используется следующий алгоритм:

Ввести количество элементов массива.
Ввести элементы массива.
Найти индексы максимального и минимального элементов.
Определить границы участка массива между найденными элементами.
Последовательно просмотреть элементы, расположенные между границами.
Найти сумму отрицательных элементов.
Вывести полученный результат.
Подробное описание выполнения работы
1. Анализ условия задачи
На первом этапе было проанализировано условие задачи. Определено, что необходимо работать не со всеми элементами массива, а только с теми, которые расположены между минимальным и максимальным элементами. При этом учитываются только отрицательные значения.

Для решения задачи было принято решение сначала определить положение минимального и максимального элементов, а затем выполнить просмотр только необходимой части массива.

2. Ввод исходных данных
В начале работы программа запрашивает количество элементов массива.

N = int(input("Введите количество элементов массива: "))
После этого пользователь вводит элементы массива через пробел.

A = list(map(int, input("Введите элементы массива: ").split()))
Использование функции split() позволяет разделить введённую строку на отдельные значения, а функция map() преобразует их в целые числа.

3. Поиск минимального и максимального элементов
После ввода данных первый элемент массива принимается одновременно за минимальный и максимальный.

max_index = 0
min_index = 0
Далее выполняется последовательный просмотр всех элементов массива.

for i in range(1, N):
Во время обхода массива каждое значение сравнивается с текущими минимальным и максимальным элементами.

Если найден элемент, превышающий текущий максимум, запоминается его индекс.

if A[i] > A[max_index]:
    max_index = i
Если найден элемент меньше текущего минимума, также сохраняется его индекс.

if A[i] < A[min_index]:
    min_index = i
После завершения цикла известны положения минимального и максимального элементов массива.

4. Определение границ поиска
Минимальный элемент может располагаться как раньше максимального, так и позже него. По этой причине необходимо определить правильный порядок обхода массива.

Если максимальный элемент расположен левее минимального, левая граница принимает значение max_index, а правая — min_index.

if max_index < min_index:
    left = max_index
    right = min_index
else:
    left = min_index
    right = max_index
Таким образом обеспечивается корректный просмотр элементов независимо от их расположения.

5. Вычисление суммы отрицательных элементов
Перед началом вычислений создаётся переменная для хранения результата.

sum_negative = 0
Далее выполняется просмотр только тех элементов массива, которые находятся между найденными границами.

for i in range(left + 1, right):
Для каждого элемента выполняется проверка.

if A[i] < 0:
Если значение отрицательное, оно добавляется к общей сумме.

sum_negative += A[i]
Положительные элементы и нули в вычислениях не учитываются.

6. Вывод результата
После завершения обработки массива программа выводит найденную сумму отрицательных элементов.

print("Сумма отрицательных элементов =", sum_negative)
Исходный код программы
# Ввод количества элементов массива
N = int(input("Введите количество элементов массива: "))

# Ввод элементов массива
A = list(map(int, input("Введите элементы массива: ").split()))

# Первый элемент считается одновременно максимальным и минимальным
max_index = 0
min_index = 0

# Поиск индексов максимального и минимального элементов
for i in range(1, N):

    if A[i] > A[max_index]:
        max_index = i

    if A[i] < A[min_index]:
        min_index = i

# Определение границ участка массива
if max_index < min_index:
    left = max_index
    right = min_index
else:
    left = min_index
    right = max_index

# Вычисление суммы отрицательных элементов
sum_negative = 0

for i in range(left + 1, right):

    if A[i] < 0:
        sum_negative += A[i]

# Вывод результата
print("Сумма отрицательных элементов =", sum_negative)
