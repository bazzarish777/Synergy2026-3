Анализ условия задачи
На первом этапе я внимательно изучил условие задачи и определил, какой результат необходимо получить.
Дан одномерный массив \(A\), состоящий из \(N\) целых чисел. Требуется найти сумму отрицательных элементов, расположенных между максимальным и минимальным элементами массива.
Для решения задачи необходимо выполнить следующие действия:
1. Ввести количество элементов массива.
2. Заполнить массив целыми числами.
3. Найти минимальный элемент массива.
4. Найти максимальный элемент массива.
5. Определить позиции минимального и максимального элементов.
6. Просмотреть элементы, находящиеся между этими позициями.
7. Вычислить сумму только отрицательных элементов.
8. Вывести полученный результат на экран.
При этом сами минимальный и максимальный элементы в сумму не включаются.
Шаг 2. Выбор языка программирования
Для решения задачи был выбран язык программирования C++.
Данный язык позволяет эффективно работать с массивами, выполнять математические операции и использовать стандартные алгоритмы для поиска минимальных и максимальных значений.
Для реализации программы были выбраны следующие инструменты:
- iostream — для ввода исходных данных и вывода результата;
- vector — для хранения элементов массива;
- algorithm — для использования функций поиска минимального и максимального элементов.
Шаг 3. Создание и заполнение массива
На данном этапе программа получает количество элементов массива и значения каждого элемента.
Сначала считывается число \(N\), которое определяет размер массива. Затем создаётся массив A, содержащий \(N\) элементов.
Для ввода значений используется цикл for, который последовательно считывает все элементы массива.
Например, пользователь вводит:
7
2 -4 9 -3 1 -8 5


Первое число 7 обозначает количество элементов, а последующие числа являются элементами массива.
В результате формируется массив:
\[
A=[2,-4,9,-3,1,-8,5]
\]

После этого программа может выполнять поиск необходимых элементов.
Шаг 4. Поиск минимального элемента
Следующим действием является поиск минимального элемента массива.
Для этого используется стандартная функция C++ min_element().
Она позволяет определить наименьшее значение среди всех элементов массива.
В рассматриваемом примере:
\[
A=[2,-4,9,-3,1,-8,5]
\]

Минимальным элементом является:
\[
A_{\min}=-8
\]

Его индекс при нумерации с нуля равен 5.
Полученный индекс необходим для определения границ участка массива, в котором будет выполняться суммирование.
Шаг 5. Поиск максимального элемента
После нахождения минимального элемента необходимо определить максимальный элемент массива.
Для этого применяется функция max_element().
В рассматриваемом примере максимальным элементом является:
\[
A_{\max}=9
\]

Его индекс равен 2.
Таким образом, программа получила два значения:
- минимальный элемент: \(-8\), индекс 5;
- максимальный элемент: \(9\), индекс 2.
Теперь необходимо определить, какие элементы находятся между ними.
Шаг 6. Определение границ участка массива
Поскольку максимальный и минимальный элементы могут располагаться в любом порядке, необходимо определить левую и правую границы участка.
Для этого сравниваются индексы найденных элементов.
Левой границей становится меньший индекс, а правой — больший.
В программе это реализуется следующим образом:
int left = min(minIndex, maxIndex);
int right = max(minIndex, maxIndex);


В нашем примере:
\[
left=2,\qquad right=5
\]

Следовательно, необходимо рассмотреть элементы с индексами 3 и 4.
Это значения:
\[
[-3,1]
\]

Сами элементы с индексами 2 и 5 не учитываются, поскольку они являются максимальным и минимальным элементами массива.
Шаг 7. Вычисление суммы отрицательных элементов
После определения границ начинается основной этап решения задачи — вычисление суммы отрицательных элементов.
Сначала переменной sum присваивается нулевое значение:
long long sum = 0;


Затем программа последовательно перебирает элементы между найденными границами.
Для каждого элемента проверяется условие: является ли он отрицательным.
Если значение меньше нуля, оно добавляется к общей сумме. Если элемент положительный или равен нулю, он пропускается.
Для нашего массива:
Элемент	Условие	Действие
-3	Меньше нуля	Добавляем к сумме
1	Больше нуля	Пропускаем
Таким образом:
\[
S=-3
\]

Это и есть искомая сумма отрицательных элементов между максимальным и минимальным значениями массива.
Шаг 8. Вывод результата
После завершения перебора программа выводит итоговое значение на экран.
Для этого используется команда:
cout << sum << '\n';


Для рассмотренного примера результат будет следующим:
-3


Если между максимальным и минимальным элементами нет отрицательных значений, программа выведет 0.
Шаг 9. Тестирование программы
После написания программы необходимо проверить правильность её работы на различных входных данных.
Для этого были рассмотрены следующие тестовые примеры.
Тест 1. Отрицательный элемент между экстремумами
Входные данные
7
2 -4 9 -3 1 -8 5


Результат
-3


Между максимумом 9 и минимумом -8 находится отрицательный элемент -3.

Тест 2. Отрицательных элементов между границами нет
Входные данные
4
1 5 9 3


Результат
0


Между минимумом 1 и максимумом 9 находится только положительный элемент 5.

Тест 3. Все элементы отрицательные
Входные данные
4
-10 -2 -5 -8


Результат
-13


Между минимумом -10 и максимумом -2 находятся элементы -5 и -8. Их сумма равна -13.

Тестирование позволяет убедиться, что программа правильно находит экстремальные элементы, определяет границы и суммирует только отрицательные значения.
Шаг 10. Оценка эффективности алгоритма
После проверки программы была оценена её вычислительная сложность.
Поиск минимального элемента выполняется за \(O(N)\). Поиск максимального элемента также выполняется за \(O(N)\). Перебор элементов между найденными позициями занимает не более \(O(N)\).
Следовательно, общая временная сложность алгоритма составляет:
\[
O(N)
\]

Для хранения массива используется дополнительная память размером \(N\), поэтому пространственная сложность равна:
\[
O(N)
\]

Таким образом, программа эффективно работает с массивами различных размеров и не требует сортировки исходных данных.

Заключение
В ходе выполнения кейс-задачи была разработана программа на языке C++, предназначенная для нахождения суммы отрицательных элементов, расположенных между максимальным и минимальным элементами одномерного массива.
Работа выполнялась последовательно: сначала были проанализированы условия задачи, затем создан и заполнен массив, найдены его минимальный и максимальный элементы, определены границы участка и вычислена сумма отрицательных значений. После этого программа была проверена на различных тестовых данных и оценена с точки зрения эффективности.
В результате поставленная задача решается за линейное время \(O(N)\). Программа не требует предварительной сортировки массива и корректно обрабатывает случаи, когда между экстремальными элементами отсутствуют отрицательные значения.
Таким образом, цель кейс-задачи достигнута: разработан алгоритм, реализована программа и подготовлен проект для публикации на GitHub.
